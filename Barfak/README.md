# Barfak ❄️ — برف روی دسکتاپ مک

یک برنامه‌ی کوچک نوار منو برای macOS 13 به بالا که روی کل صفحه برف می‌باراند.

- برف روی لبه‌ی بالای پنجره‌ها و پایین صفحه با سطح ناهموار می‌نشیند؛ با جابه‌جا کردن پنجره، برف پایین می‌ریزد
- برف روی آیکون‌های دسکتاپ و داک (به اجازه‌ی Accessibility نیاز دارد)
- برف روی سوژه‌ی تصویر پس‌زمینه (آزمایشی، macOS 14 به بالا)
- ریسه‌ی چراغ چشمک‌زن بالای هر پنجره با چهار مدل لامپ
- برف‌روب که با پر شدن برفِ پایین صفحه از آن عبور می‌کند
- با کلیک و کشیدن روی برفِ پایین صفحه گلوله‌ی برفی ساخته می‌شود؛ سه گلوله روی هم یک آدم‌برفی می‌شود
- تله‌کابین: از قرقره‌ی بالا-وسط صفحه بکشید و روی پنجره یا آیکون رها کنید؛ کلیک ساده روی قرقره آخرین طناب را برمی‌دارد
- دانه‌ها از نشانگر ماوس فاصله می‌گیرند و با ماوس می‌توان برفِ نشسته روی پنجره‌ها را کنار زد
- آدم‌برفی قابل جابه‌جایی که چشم‌هایش ماوس را دنبال می‌کند و با کلیک تکان می‌خورد
- همه‌ی این‌ها از منوی ❄ در نوار منو روشن و خاموش می‌شوند
- پشتیبانی از چند نمایشگر

## ساخت

به Xcode یا Command Line Tools نیاز است (`xcode-select --install`).

```bash
./Scripts/build-app.sh
```

```bash
open build/Barfak.app
```

برای اجرای سریع بدون ساختن بسته‌ی `.app`:

```bash
swift run -c release
```

## ساختار

| فایل | کار |
| --- | --- |
| `AppDelegate.swift` | منوی نوار منو و پنجره‌های شفاف روی هر نمایشگر |
| `SnowScene.swift` | شبیه‌سازی برف، برف‌روب، گلوله‌های برفی، تله‌کابین و ماوس |
| `Entities.swift` | دانه، توده‌ی برف، ریسه‌ی چراغ، گلوله‌ی برفی، طناب |
| `Art.swift` | همه‌ی تصاویر که با کد کشیده می‌شوند |
| `WindowTracker.swift` | قاب پنجره‌های باز |
| `AXTracker.swift` | قاب آیکون‌های دسکتاپ و داک از طریق Accessibility |
| `Wallpaper.swift` | تشخیص سوژه‌ی تصویر پس‌زمینه با Vision |
| `SnowmanPanel.swift` | آدم‌برفی |
| `Settings.swift` | تنظیمات ذخیره‌شده |
