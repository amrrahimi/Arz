# Barfak ❄️ — برف روی دسکتاپ مک

یک برنامه‌ی کوچک نوار منو برای macOS 13 به بالا که روی کل صفحه برف می‌باراند.

- برف روی لبه‌ی بالای پنجره‌ها و پایین صفحه می‌نشیند؛ با جابه‌جا کردن پنجره، برف پایین می‌ریزد
- دانه‌ها از نشانگر ماوس فاصله می‌گیرند و با ماوس می‌توان برفِ نشسته را کنار زد
- آدم‌برفی قابل جابه‌جایی که چشم‌هایش ماوس را دنبال می‌کند و با کلیک تکان می‌خورد
- تنظیم شدت بارش، باد، توقف/ادامه و اجرا هنگام ورود به سیستم از منوی ❄ در نوار منو
- کلیک‌ها از لایه‌ی برف عبور می‌کنند؛ به هیچ مجوزی (Screen Recording و …) نیاز ندارد
- پشتیبانی از چند نمایشگر

## ساخت

به Xcode یا Command Line Tools نیاز است (`xcode-select --install`).

```bash
./Scripts/build-app.sh
```

```bash
open build/Barfak.app
```

برای اجرای سریع بدون ساختن بسته‌ی `.app`:

```bash
swift run -c release
```

## ساختار

| فایل | کار |
| --- | --- |
| `AppDelegate.swift` | منوی نوار منو و پنجره‌های شفاف روی هر نمایشگر |
| `SnowScene.swift` | شبیه‌سازی دانه‌ها و توده‌های برف با SpriteKit |
| `WindowTracker.swift` | خواندن قاب پنجره‌های باز برای نشستن برف |
| `SnowmanPanel.swift` | آدم‌برفی |
| `Settings.swift` | تنظیمات ذخیره‌شده |
